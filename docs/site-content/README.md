## 修改或恢复方法

1. 先核对线上是否有更新，不用旧副本覆盖后来内容。
2. 欢迎正文在现有主题 5 编辑；三个模板在对应分类的 Edit → Advanced settings → Template 编辑。修改前模板与标题提示均为空。
3. 邮箱白名单修改前为空；如需调整，先评估注册影响再按新的授权处理。用户字段不要为了恢复外观直接删除，以免丢失成员已填写的数据；可先调整显示与必填要求。
4. 保存后刷新核对，模板还需打开新主题编辑框检查；不发布无意义测试内容。
5. 将前后值、理由、结果及未验证事项记入 OPERATIONS_LOG.md，并同步本目录与相关 Issue。回退也需要记录，不删除历史日志。
