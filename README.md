## 状态如何理解

本记录综合此前对话、已保存的 Word 报告及本轮 GitHub 核对。不能把“用户提出要求”“点击过保存”和“当前已经生效”视为同一件事。

- **本轮已核验**：本地历史报告存在；原仓库内容和本轮上传资料可通过仓库记录核对。
- **历史完成记录**：先前对话或报告记载已完成，但 2026-10-27 未重新登录论坛后台全面检查。
- **待核验**：旧资料有冲突、缺少原始链接或实际状态可能变化。
- **仅建议 / 未实施**：研究或讨论过，不能据此声称网站已修改。
- **未完成**：有明确执行障碍或没有成功结果。

除明确标注外，下列论坛状态均属于历史记录。早期操作没有可可靠恢复的逐日时间戳，因此按实际对话顺序整理，不补造日期。

## 按顺序记录的每一步进展

### 1. 明确需求与选择论坛

用户希望在书院内连接在校生和毕业生，分享经验、资源及机会，最初要求推荐易实现的论坛方案，随后选择直接试用 Discourse 免费托管。此阶段确定了“先有可体验的论坛，再推进运营”的方向，没有开发独立论坛程序。

**结果：** 使用现成 Discourse 服务。**证据：** 用户要求与后续站点地址。没有记录可证明评估过的所有备选产品或完整成本比较，故不补写。

### 2. 注册托管站点并完成初始设置

用户完成登录，并明确要求社区名用英文、网址简洁；多次确认继续、提交及保留所选设置。流程从 Discourse 创建页面进入站点配置，最终使用上述正式论坛地址。

**历史结果：** MCMC Alumni Network 上线。**待核验：** 当前托管方案、配额、服务条款和实际可用功能；不能由旧“免费版”记录推断未来方案永远不变。

### 9. 研究邮箱筛选及其他改进（2026-10-27）

用户询问能否限制论坛注册邮箱格式，筛选非澳门大学人员，并要求提出类似优化建议。本阶段只做研究和建议，**没有修改站点**。

| 建议方向 | 已研究到的信息 | 仍需决定或验证 |
| --- | --- | --- |
| 邮箱域名限制 | Discourse 有 `allowed_email_domains`；填写域名，不带 `@`。允许域名也会涵盖其子域名 | 当前免费方案、Discourse ID 注册路径与实际注册行为；毕业生例外流程 |
| 澳大邮箱覆盖 | UM@Connect 使用 `[studentID]@connect.um.edu.mo`，属终身邮箱服务；澳大说明部分旧邮箱别名会随毕业停用 | 不能假设所有毕业生已经开通；需要覆盖旧届、不同邮箱情况 |
| 限定范围 | `connect.um.edu.mo` 较具体；`um.edu.mo` 更宽，包含子域名 | 两者均不能单凭邮箱证明满珍归属；是否接受全澳大成员待讨论 |
| 成员资料 | 可研究学生/毕业生、书院关系、毕业年份、专业、行业和可提供帮助等字段 | 自填信息不是认证，必填项应尽量少，实际方案支持及可见性须核验 |
| 新成员引导 | 曾建议简短双语欢迎页，以及 Ask Alumni / Share Opportunity / Introduce Yourself 三个入口；发帖模板包括背景、问题、截止时间、来源 | 未创建；需结合现有栏目决定 |
| 隐私与角色 | 邮箱准入不等于内容私密；TL4 有管理他人主题的能力，不宜当作荣誉校友标签 | 公开信息边界、管理员/版主/TL4 职责和反垃圾策略 |

关于邮箱：限制邮箱能帮助控制注册来源，但不能等同于身份核验、满珍成员证明或澳大单点登录。没有验证邀请链接能绕过限制、限制是否影响现有账号，不能作承诺。相关官方依据见 [REFERENCES](docs/REFERENCES.md)。
